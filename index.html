ABOUT THE PROJECT

익숙한 게임, 분리된 전용 환경

기본 게임 설치를 보존하면서 전용 폴더에 공식 게임 파일과 Fabric 환경을 구성하도록 개발하고 있습니다. 서버는 사용자가 직접 선택하며, 런처 실행만으로 자동 접속하지 않습니다.

01 / ACCOUNT

공식 Microsoft 인증

Microsoft 공식 페이지에서 로그인합니다. 런처가 Microsoft 비밀번호를 직접 입력받지 않으며, 정품 계정과 게임 소유권 확인을 통과해야 실행하도록 설계합니다.

02 / INSTALLATION

공식 파일과 Fabric

원본 게임을 패키지에 재배포하지 않습니다. 공식 배포 경로와 검토된 모드 구성을 사용하고, 다운로드 파일의 무결성을 확인하도록 개발합니다.

PRIVACY & SECURITY

비밀번호를 받지 않는 로그인

현재 개발판은 Microsoft MSAL의 공식 기기 코드 인증을 사용합니다. Microsoft 인증 캐시는 Windows 사용자별 DPAPI로 암호화하여 기기에 저장하며, Xbox와 Minecraft 인증 토큰은 메모리에서 처리합니다. 로그에는 비밀번호, 인증 토큰, 로그인 코드를 기록하지 않습니다.

계정 인증 과정에서는 Microsoft, Xbox, Minecraft 서비스가 인증 요청을 처리합니다. 런처 로그아웃은 로컬 Microsoft 인증 캐시를 삭제하며, 다른 브라우저나 서비스의 로그인 상태까지 종료하지 않습니다.

이 소개 페이지는 외부 글꼴, 광고, 분석 도구, 쿠키 또는 입력 양식을 포함하지 않습니다. 소개 페이지는 GitHub Pages로 제공합니다. 호스팅 제공자는 서비스 운영과 보안을 위해 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인하세요. 프로젝트 문의는 공개 문의 게시판을 이용해 주세요. 게시판에는 비밀번호나 인증 토큰을 올리지 마세요.

FOR APPLICATION REVIEWERS

MongMongWay Launcher

MongMongWay Launcher is an independently developed Windows launcher for legitimate Minecraft: Java Edition owners. Its intended purpose is to manage an isolated official game installation and a reviewed Fabric configuration for two public server networks: BIG and PLAY.

The development build uses Microsoft's MSAL device-code flow through the official Microsoft sign-in page. Microsoft passwords are never collected by the launcher. The Microsoft authentication cache is protected using Windows DPAPI for the current user. Xbox and Minecraft tokens are held in memory and excluded from diagnostic logs. The launcher does not provide offline authentication bypasses.

Microsoft and Xbox authentication have been tested on the development PC. Minecraft API access is currently blocked by an Invalid app registration response. Minecraft ownership verification, end-to-end game launches, and server joins have not passed validation. There is no public binary download at this stage.

The project uses established open-source components including MSAL.NET and CmlLib, rather than replacing their authentication and installation functionality. Original game files will be downloaded from permitted official distribution endpoints and will not be bundled or redistributed with the launcher.
